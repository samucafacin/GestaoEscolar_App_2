# Gestão Escolar App 🏫

Sistema de Gestão Escolar desenvolvido em Java Swing para cadastro e gestão de Espaços e Recursos Educacionais.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Java (JDK 17+)
* **Interface Gráfica:** Java Swing
* **IDE:** IntelliJ IDEA
* **Controle de Versão:** Git & GitHub

---

## 📁 Estrutura do Projeto

* `br.com.escola.app`: Classe principal (`Main.java`) que inicia a aplicação.
* `br.com.escola.models`: Classes de modelo (`Espaco.java`, `RecursoEducacional.java`).
* `br.com.escola.repository`: Banco de dados temporário em memória (`BancoMemoria.java`).
* `br.com.escola.views`: Interfaces gráficas em Swing (`MenuPrincipal.java`, `CadastroEspacoFrame.java`, `CadastroRecursoFrame.java`).
